# Setup
1. Run Chris Titus Utility and debloat Windows.
2. Uninstall Edge, One Drive, Windows Media Player, Notepad, MS Paint, Copilot and other bloat.
3. Re-install Clock, if it gets deleted.
4. Go to Regedit and fix the Education Edition issue, if you see something like 'This is managed by your organization.'
5. Make a New template for New Empty File using Regedit.
